# Learner Reflection Template

**When:** After Michael completes a domain walkthrough (in-app, fresh progress).  
**Time:** ~5 minutes.  
**Store:** `.cursor/plans/ccna-pedagogy-audits/reflections/wave-N-[domain-id].md`

---

## Copy per domain

```markdown
# Learner reflection — [Domain name]

**Wave:** N  
**Date:** YYYY-MM-DD  
**Domain ID:** `domain-id`  
**Walkthrough result:** PASS / BOUNCE (list topics)

## Questions

### Where did I hesitate?
<!-- Pause points, re-reads, confusion -->

### What surprised me?
<!-- Unexpected difficulty or ease -->

### What felt smooth?
<!-- Flow that worked -->

### What did I immediately forget?
<!-- Concepts that didn't stick after one read -->

### What explanation made something click?
<!-- Delight moment — reproduce in other topics -->

## Patterns (optional)
<!-- Themes to feed back into BLS or path doc -->

## Oral mastery check (required for reference experiences)

**Score:** _/10  
**Struggled on (lesson gaps, not self-blame):**
<!-- e.g. frame vs packet nesting, Transport vs Network -->

**Ready to explain without jargon:**
<!-- one sentence the lesson should have equipped you to say -->

## Sign-off
- [ ] Ready for next domain
- [ ] Needs another implement pass (list topics)
```

---

## Why this matters

Agents can say "looks good." Only a learner can say "I felt confused." Reflection notes become ReLearn's pedagogy IP — how we teach, not just what we teach.

After six domains, review all reflection files for recurring patterns (e.g. "too many protocols per step") and update [`bridge-learning-standard.md`](bridge-learning-standard.md).
