Why a subnet mask is not just “the network part.”

A subnet mask is a decision boundary. It tells a device which destinations are local, which require a router, and how large the address space is. That same boundary can be expressed three ways.

I understand that /27 leaves five host bits, but why does that turn into blocks of 32?

Professor

Because five bits can form 32 distinct patterns: from 00000 through 11111. Those patterns are the 32 addresses inside each block. The subnet does not “choose” 32 arbitrarily—the remaining bit combinations force it.

Subnet Masks

Subnet mask mental model

Saved

A subnet mask is a boundary decision, not just a formatting trick. It answers: “Is the destination inside my local neighborhood?”

The remaining host bits create all possible addresses inside the block. Five bits means 2⁵ = 32 total patterns.

/27 → 11111111.11111111.11111111.11100000

27 fixed network bits · 5 changeable host bits

My shortcut: block size = 256 minus the interesting octet. For 255.255.255.224, that is 256 − 224 = 32.
