## Why this exists

ReLearn does not ask AI to **build** the course first.

It asks AI to **critique** the course:

```text
Evidence
   ↓
Mechanical QA
   ↓
Vision Review
   ↓
Pedagogy triage (ChatGPT)
   ↓
Human approval
   ↓
Curriculum updated
```

That is a **Curriculum Review Board**, not a chatbot that authors content unsupervised.

Tonight’s CCNA run proved the shape: Playwright verified flow (21/21), the vision judge produced many observations (mostly noise, a few gold), triage decides what matters, and Michael keeps sign-off.

The same board reviews any content pack that fills a ReLearn template — CCNA today; A+, Git, Biology, Jazz, French later — **without changing the pipeline**, only the content pack.

---

## Ownership (non-negotiable)

| Role | Does | Does not |
|------|------|----------|
| Playwright / evidence | Prove the lesson runs; capture screens | Decide pedagogy taste |
| Vision judge | Propose findings | Auto-edit curriculum |
| ChatGPT triage | Classify findings with board labels | Merge to `dev` |
| Track owner (Michael for CCNA) | Approve decisions; walkthrough; Topic Complete | Outsource final taste |
| Implementation agent | Ship only **Ship Before Sign-off** items | Invent new quality scores |

Agents never auto-merge curriculum from judgments.

## Pipeline stages

| Stage | Question | Artifact |
|-------|----------|----------|
| **Evidence** | What did the learner see? | `reports/ccna-evidence/<topic>/` |
| **Mechanical QA** | Does the lesson work? | `reports/ccna-ux-audit.md` |
| **Vision Review** | How does it feel? | `reports/ccna-judgment/` |
| **Pedagogy triage** | Which observations matter? | ChatGPT + [`decision-log`](../.cursor/plans/ccna-pedagogy-audits/review-board/decision-log.md) |
| **Human approval** | Do I agree? | Ledger `approvedBy` + walkthrough |
| **Curriculum updated** | Fix shipped? | PR/commit on ledger + scoreboard |

## Triage labels (canonical)

| Label | Meaning | When to use |
|-------|---------|-------------|
| **Ship Before Sign-off** | Must fix before Topic Complete | Blockers / high-confidence learner harm |
| **Improve Later** | Real issue; post–sign-off backlog | Valid but not blocking launch of the topic |
| **Intentional Design** | Conscious non-fix | We chose this on purpose — not “AI was wrong” |

Intentional Design is the durable answer six months later: *we decided not to solve this yet*, recorded with reason.

## Decision ledger

**Committed path:** [`.cursor/plans/ccna-pedagogy-audits/review-board/decision-log.md`](../.cursor/plans/ccna-pedagogy-audits/review-board/decision-log.md)

Required fields per finding:

- `findingId` — stable ID (`topicId__checkpoint__category__shortHash`)
- `topicId`
- `severity` / `category` / `checkpoint`
- `observation` (short)
- `originalRecommendation`
- `decision` — `ship-before-signoff` \| `improve-later` \| `intentional-design` \| *(empty = pending)*
- `reason`
- `approvedBy`
- `date`
- `prOrCommit` — filled when implemented
- `auditBatch` — e.g. `2026-07-14-full`

**Rules:**

1. Same `findingId` on re-audit → look up the ledger first.
2. Do not re-open **Intentional Design** without updating `reason`.
3. Seed HIGH (and later promoted) findings only — do not dump every MEDIUM/LOW into the ledger on day one. Append when triage promotes them.
4. Ledger lives in git (not under gitignored `reports/`).

## Factual sign-off scoreboard

**Committed path:** [`.cursor/plans/ccna-pedagogy-audits/review-board/ccna-scoreboard.md`](../.cursor/plans/ccna-pedagogy-audits/review-board/ccna-scoreboard.md)

Per-topic columns (factual only):

| Column | Meaning |
|--------|---------|
| Mechanical | pass / warn / fail from last full audit |
| Evidence | yes / no |
| Findings triaged | none / partial / complete (ledger rows for that topic) |
| Ship-before blockers open | count of ship-before rows with empty `prOrCommit` |
| Human walkthrough | pending / pass / bounce |
| Topic Complete | YES / NO (wave sheets remain DoD home) |

**Do not** put AI quality scores (94/100) or soft-heuristic averages on this board. Soft scores are triage aids only.

Wave sheets under `.cursor/plans/ccna-pedagogy-audits/wave-*.md` still record Topic Complete sign-off. The scoreboard is the operational dashboard.

## Finding ID format

```text
{topicId}__{checkpoint}__{category}__{shortHash}
```

`shortHash` = first 8 hex chars of SHA-256 over the observation text. Stable across re-export of the same observation.

Generated by `npm run audit:chatgpt-export` when building the triage dossier.
